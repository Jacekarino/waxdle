Waxdle Daily

    How to Play

    Guess the album cover in 6 tries.

    • Can you guess the album from a cropped version of the cover art?
    • If you guess the album right, you get the full credit (green dot).
    • If you guess the artist right, you get a partial credit (yellow dot).
    • If you guess the artist wrong, you get nothing (red dot).
    • Each guess must be a valid album from the search dropdown.
    • After each guess, the image zooms out revealing more of the cover art.
    • Play the Daily mode to test your skills, or Endless mode to practice.

    Thanks for playing!

    Made with ♡ by Jacekarino

    This is an open-source prototype / proof of concept. The game is functional, but may have issues. Done in a day for fun and as a learning experience and a portfolio piece. Waxdle uses LastFM API for fetching the cover arts. The code is public on GitHub if you're curious about the inner workings. You can definitely cheat by looking up the albums database by the way.
