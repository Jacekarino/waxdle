# Web app description:

A visual puzzle daily game where music fans must guess a legendary album cover. Inspired by Wordle.

# Running the project:

https://waxdle.pages.dev/

Alternatively: Open index.html in your browser of choice.

To fetch new data, create an .env file with LASTFM_API_KEY=your-api-key-here, then run:

```bash
npm install
node fetch-albums.js
```
